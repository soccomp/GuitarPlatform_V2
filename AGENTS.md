# AGENTS.md

This file gives coding agents the project-specific context needed to work safely in this repository.

## Project Overview

Guitar Learning Platform is a local-first personal guitar learning workspace. It combines:

- System courses: course videos, lesson materials, transcripts, and coach Q&A.
- Learning videos: locally collected videos scanned from `library/collected/`.
- Song practice: song folders with PDF/GP tabs, audio tracks, videos, markers, A/B looping, and speed controls.

The app is not a public content platform. Treat it as a local personal knowledge and practice tool, where filesystem paths, local media, and index refresh behavior matter.

## Tech Stack

- Frontend: Vue 3 + Vite in `frontend/`.
- Backend: FastAPI in `backend/`.
- Tests: Python `unittest` under `backend/tests/`.
- Local resources: `library/courses/`, `library/collected/`, and `library/songs/`.

Default local service URLs:

- Frontend: `http://127.0.0.1:3000/`
- Backend: `http://127.0.0.1:8000/`

Note: `backend/main.py` uses port `8765` only when run directly with `python backend/main.py`; the project service scripts and docs expect backend port `8000`.

## Repository Layout

```text
backend/     FastAPI app, routers, services, data index, backend tests
frontend/    Vue 3 app and Vite config
library/     Local user media and learning resources; mostly ignored by Git
scripts/     Local launch, service, install, and packaging scripts
docs/        Product, development, AI planning, changelog, and package docs
coach_node/  Additional coach-related Python code and tests
```

Important backend areas:

- `backend/routers/`: HTTP API routes for courses, songs, videos, and coach features.
- `backend/services/indexer.py`: scans local course, song, and collected video libraries.
- `backend/services/resource_manager.py`: deletes local resources and refreshes indexes.
- `backend/services/media_response.py`: serves media with HTTP Range support.
- `backend/data/index.json`: generated/persisted library index. Be careful before editing by hand.

Important frontend areas:

- `frontend/src/App.vue`: top-level tab shell.
- `frontend/src/views/SystemCourses.vue`: system course UI.
- `frontend/src/views/LearningVideos.vue`: collected learning video UI.
- `frontend/src/views/Songs.vue`: song practice UI.
- `frontend/src/components/`: shared Vue components.

## Setup And Run

Install backend dependencies:

```bash
python3 -m pip install -r backend/requirements.txt
```

Install frontend dependencies:

```bash
npm install --prefix frontend
```

Run with the project launcher:

```bash
scripts/start_guitar_platform.command
```

Manage local services:

```bash
scripts/control_guitar_platform.command
```

Manual development commands:

```bash
uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload
npm run dev --prefix frontend
```

## Validation

Before handing off meaningful code changes, run the narrowest relevant checks. For broad changes, run:

```bash
python3 -m unittest discover -s backend/tests -v
npm run build --prefix frontend
python3 -m py_compile backend/main.py backend/routers/courses.py backend/routers/songs.py backend/routers/videos.py
```

CI also installs `backend/requirements.txt`, runs backend unit tests, and builds the frontend.

There is currently no committed frontend lint script in `frontend/package.json`; do not claim lint passed unless a lint command is added and run.

## Data, Secrets, And Local Media

Do not commit secrets or real local learning assets.

- `backend/.env` is local-only and ignored.
- MiniMax settings live in `backend/.env` when AI assistant features are used:

```env
MINIMAX_API_KEY=...
MINIMAX_BASE_URL=https://api.minimaxi.com/anthropic/v1/messages
```

- `library/courses/*`, `library/songs/*`, and `library/collected/*` are ignored except for `.gitkeep` placeholders.
- `library/collected/.thumbnails/` is generated by video scanning.
- `backend/data/coach_recordings/` and `backend/data/coach_sessions.json` are local generated data.

Avoid adding real videos, audio files, PDFs, GP files, recordings, or API keys to commits.

## Development Guidelines

- Preserve the local-first workflow. File paths should remain relative to the expected `library/` roots when stored in indexes or returned to the frontend.
- Prefer the existing scanner and resource-manager services over ad hoc filesystem edits.
- Keep HTTP Range behavior working for video, audio, PDF, and GP resources.
- For backend path handling, use `pathlib.Path` and validate paths stay inside the intended library directory.
- When adding or changing scan behavior, update or add focused tests in `backend/tests/`.
- Avoid manual edits to `backend/data/index.json` unless the task is explicitly about fixture/index data. Prefer scan endpoints or service functions.
- Keep frontend changes consistent with the existing compact, dark, practice-workbench UI. This is an app interface, not a marketing site.
- Vue code uses `<script setup>` in existing files. Follow that pattern unless there is a clear reason not to.
- Do not introduce new frameworks, state managers, or UI libraries unless the task genuinely needs them.

## Useful API Entry Points

Common scan endpoints:

- `GET /api/courses/scan?persist=true`
- `GET /api/videos/scan?persist=true`
- `GET /api/songs/scan?persist=true`

Static mounts:

- `/library`: serves files from `library/`
- `/data`: serves files from `backend/data/`

## Git Hygiene

- Check `git status --short` before editing.
- Do not revert user changes or generated local data unless explicitly asked.
- Keep edits scoped to the request.
- If modifying ignored local-service files, confirm whether they are intended to stay local.
- Mention any tests or builds that were not run in the handoff.
