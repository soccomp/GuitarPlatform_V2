# 2026-05-04 工作总结

编写日期：`2026-05-04`  
编写人：`Codex`

## 1. 今日目标

今天这轮工作的核心，不是再往平台里堆更多零散功能，而是把平台进一步推进成一个更像：

- 本地吉他学习工作台
- 内容知识库
- 轻量学习教练

围绕这个目标，今天重点做了三条主线：

1. 强化 `歌曲练习 -> 下一步该练什么`
2. 给 `学习视频` 建立 transcript / 摘要 / 标签 / 推荐画像
3. 给 `系统教材` 建立 transcript / 摘要 / 标签 / 推荐画像

---

## 2. 已完成内容

### 2.1 歌曲练习：学习教练从“推荐”升级为“可执行流程”

今天把 `下一步该练什么` 进一步做成了一个可执行的轻量练琴流。

已完成：

- `当前重点`
- `为什么先练这个`
- `下一步动作`
- `推荐系统课程`
- `推荐学习视频`
- `推荐练习路径`
- `今天这样练`

并且这套流程现在支持：

- checklist 勾选
- 练习路径状态切换：`待开始 / 进行中 / 已完成`
- checklist 与路径状态联动
- 按歌曲分别保存学习状态
- 记录“今天完整练了几轮”
- 记录这首歌累计完成了几轮
- 右侧显示 `今天练了什么`

也就是说，这一块已经不再只是“AI 给建议”，而开始更像一个能落地执行的小型练习流程。

---

### 2.2 学习视频：从播放器升级成“可理解内容”

学习视频这部分今天做了系统升级。

当前单条视频详情页已支持展示：

- 内容摘要
- 适合怎么用
- 关键点
- 标签
- 文字内容预览

同时支持：

- 编辑标题
- 编辑作者 / 来源
- 编辑分类
- 编辑备注
- 编辑自定义标签
- 统计播放次数

后端新增了 `video_intelligence` 内容画像逻辑，会根据：

- 标题
- 分类
- 备注
- 标签
- transcript 文本（如果有）

自动生成：

- `learning_focus`
- `summary`
- `recommended_for`
- `key_points`
- `transcript_preview`

---

### 2.3 系统教材：课程内容画像接入完成

系统教材页不再只是视频 + transcript + 问答。

当前课程详情页新增：

- 学习重点
- 课程摘要
- 适合怎么用
- 关键点
- 文字内容预览

课程 transcript 生成后，这些内容会同步刷新，不需要手动重新整理。

后端新增了 `course_intelligence` 内容画像逻辑，会根据：

- 课程标题
- 系列 / 章节
- 标签
- transcript 文本

生成：

- `learning_focus`
- `summary`
- `recommended_for`
- `key_points`
- `transcript_preview`

---

### 2.4 transcript 工作流：从“能生成”推进到“可维护”

今天把 transcript 相关功能从“散点按钮”推进成了真正可维护的工作流。

学习视频：

- 支持单条 `生成 transcript`
- 支持 `批量补 transcript`
- 左侧显示 transcript 覆盖率
- 支持 `刷新内容理解`

系统教材：

- 左侧显示 transcript 覆盖率
- 单课支持 `生成 transcript`
- 支持 `刷新内容理解`

这意味着 transcript 已经不只是一个单独工具按钮，而开始进入平台的长期整理机制。

---

### 2.5 知识库补全清单：优先级系统上线

今天最重要的新能力之一，是给课程和视频都加上了：

- `优先补这几条`
- `优先补这几节`

平台会根据内容价值和练歌关联度，自动排出最值得优先补 transcript 的内容。

学习视频优先级考虑：

- 是否与现有歌曲直接相关
- 是否明显是 `solo / cover / 教学` 类内容
- 是否更适合直接对照练歌

系统教材优先级考虑：

- 是否更适合拿来解决节奏问题
- 是否与 solo / 乐句 / 拨弦 / 音阶类练习相关
- 是否更适合用于问答与重点提炼

这一步非常关键，因为平台开始不只是“能补 transcript”，而是开始知道：

- 先补什么最值
- 哪些内容补完后对推荐帮助最大

### 2.6 内容关联从“单向推荐”升级成“双向回跳”

之前平台已经能做到：

- 歌曲练习页推荐相关系统课程
- 歌曲练习页推荐相关学习视频

这次进一步补上了反向关联：

- 学习视频详情页会直接显示：`关联歌曲练习`
- 系统教材详情页会直接显示：`适合回到这些歌验证`
- 点一下就能直接跳回对应歌曲练习

这让平台里的关系开始变成真正的内容网络：

- 歌曲可以带出课和视频
- 课和视频也能反向带回歌曲

这一步对“平台内容的关联”很关键，因为它让用户不再只是被动看推荐，而是能在学习路径中来回穿梭。

---

### 2.6 推荐系统升级

`下一步该练什么` 这套学习教练逻辑，今天也明显升级了。

之前主要靠：

- 歌名
- 标题
- 少量规则

现在已经开始同时吃：

- 学习视频摘要
- 学习视频学习重点
- 学习视频关键点
- 学习视频标签
- 系统课程摘要
- 系统课程学习重点
- 系统课程关键点
- 系统课程标签

也就是说，推荐开始真正建立在“内容理解”之上，而不是只建立在浅层命名匹配上。

## 5. 当前判断

今天进一步验证了一件事：

**这个平台里最有价值的 AI，不是“像真人老师一样说很多话”，而是“理解你现有内容、整理知识、提炼重点、安排下一步练习”。**

也因此，当前最值得继续投入的主线已经更清楚了：

- transcript 补全
- 摘要与标签体系
- 课程 / 视频 / 歌曲三者关联
- 知识库补全优先级
- 学习教练推荐

---

## 6. 下一步建议

下一阶段最值得继续推进的方向：

### 6.1 知识库补全计划

继续把当前“优先补这几条 / 这几节”推进成一个真正的补全计划：

- 今天先补哪几条视频
- 今天先补哪几节系统课
- 补完后优先提升哪些歌曲推荐能力

### 6.2 transcript 质量提升

当前 transcript 工作流已经跑通，下一步更值得做的是：

- 对学习视频 transcript 的批量补全
- 对重点课程的 transcript 优先补齐
- 对已有 transcript 再做更强的摘要 / 标签质量提升

### 6.3 首页 / 总览层

后面可以把今天新增的这些学习状态继续汇总到一个更高层入口：

- 今天练了什么
- 哪些内容已经整理好
- 哪些内容最值得优先补 transcript
- 当前学习教练建议的重点主线是什么
