# 知识库补全路线图

## 当前目标

把平台里的：

- 系统教材
- 学习视频
- 歌曲练习

逐步组织成一个可搜索、可推荐、可整理的本地吉他知识库。

---

## 已完成基础

### 1. 学习视频

- 可生成 transcript
- 可批量补 transcript
- 自动生成：
  - 学习重点
  - 内容摘要
  - 适合怎么用
  - 关键点
  - transcript 预览
- 支持优先补全清单

### 2. 系统教材

- 单课可生成 transcript
- 自动生成：
  - 学习重点
  - 课程摘要
  - 适合怎么用
  - 关键点
  - transcript 预览
- 支持优先补全清单

### 3. 学习教练

- 已开始基于课程 / 视频内容画像做推荐
- 不再只依赖歌名和标题

---

## 下一阶段

### 阶段 A：补全 transcript

目标：

- 先补高价值课程
- 先补与常练歌曲直接相关的学习视频

优先顺序：

1. 与 `歌曲练习` 直接关联的视频
2. 节奏 / solo / 拨弦 / 乐理类高频课程
3. 近期反复打开的视频与课程

### 阶段 B：优化摘要和标签

目标：

- 让每条内容不只是“有 transcript”
- 而是有更可靠的：
  - 主题
  - 技术点
  - 难点
  - 适用场景

### 阶段 C：做成知识入口

目标：

- 首页或总览层能看到：
  - 今天练了什么
  - 哪些内容已经整理好
  - 哪些内容优先值得补 transcript
  - 当前最值得补的知识点是什么

---

## 产品原则

这条路线不是为了做“看起来像 AI 的东西”，而是为了：

- 减少资料管理成本
- 让内容真正可搜索
- 让推荐建立在内容理解之上
- 让平台逐渐变成自己的长期学习知识库

---

## 当前判断

最有价值的方向不是“AI 讲很多”，而是：

- transcript 补全
- 摘要提炼
- 标签组织
- 内容关联
- 学习教练推荐

这五件事做扎实，平台的长期价值会明显超过单纯的播放器或资料文件夹。
