## [v1.2.0-dev] - 2026-05-05

### AI 学习教练与知识库
- `歌曲练习` 新增 `下一步该练什么`、`推荐练习路径`、`今天这样练`、`今天练了什么`，并支持 checklist、步骤状态、轮次统计和按歌曲保存。
- `学习视频` 与 `系统教材` 接入内容画像：学习重点、摘要、适合怎么用、关键点、transcript 预览。
- 新增 transcript 覆盖率、内容理解重建、批量补 transcript、优先补全清单，平台开始具备“知识库补全”工作流。
- 推荐系统升级为同时理解歌曲、课程、学习视频三类内容，而不再只依赖标题和歌名匹配。

### 歌曲练习与陪练
- `AI陪练` 升级为 `正常播放 / 内录混音 / 音画同录` 三模式统一控制，并新增 `Save / Retry / Cancel` 录制确认流程。
- 录制链路改为浏览器端实时混音录制，显著减少伴奏与琴声对不齐的问题。
- 新增多音频支持：同一版本下可切换多个 mp3，并用于播放、内录混音和音画同录。
- 新增打点片段保存、删除、按伴奏分组、最近练习快捷入口，以及按当前歌曲过滤的练习记录。
- `打开 GP` 改为调用 macOS 默认文件关联程序，替代网页端 alphaTab 兜底打开逻辑。

### 交互与界面
- `歌曲练习` 页面重构为更紧凑的单屏工作台，右侧拆分为 `学习教练 / AI陪练 / 练习记录` 三个标签工作区。
- 顶部新增全局大模型状态条与模型切换，并去掉页面内重复开关。
- `学习视频` 卡片、弹窗和 `系统教材` 详情页做了多轮压缩与层级梳理，提升信息密度与操作效率。
- `相关学习视频` 改为歌曲页内卡片化展示，并支持直接弹窗播放。

### 工程与交付
- 新增 4080 Windows `coach_node` 分析节点骨架、启动脚本、文档与健康检查状态接口。
- 新增不带资源的 Mac 分享包脚本与说明文档，便于在其他 Mac 上快速安装本地服务。
- 增补开发记录、AI 产品策略、知识库路线图与产品优化优先级文档。

## [v1.1.0] - 2026-04-26

### 体验升级
- 平台改为本地后台常驻服务，可直接通过 `http://127.0.0.1:3000/` 访问。
- 新增桌面服务控制器，支持重启服务和停止服务。
- 系统教材、学习视频、歌曲练习三大模块支持平台内删除资源，并自动同步刷新索引。
- 学习视频保留卡片弹窗播放体验，并进一步清理无关标签与来源展示。
- 歌曲练习页优化谱子弹窗底部播放器，支持更紧凑的拖动、A/B 设点和 `0.60x-1.00x` 速度档位。

### 技术
- 新增资源删除管理逻辑，删除后自动重扫并更新 `backend/data/index.json`。
- 学习视频删除会同步清理 `.thumbnails/` 缩略图。
- 增加后台资源删除测试，后端测试覆盖扩展到 24 项。
- 本地启动脚本升级为 launchd 常驻服务模式，支持桌面启动器与服务控制器协同工作。

### 版本说明
- 当前正式可用版升级为 `v1.1.0`。
- `frontend/package.json` 版本号同步更新为 `1.1.0`。

## [v1.0.0] - 2026-04-26

### 正式版
- 系统教材、学习视频、歌曲练习三大核心场景进入本地可用状态。
- 系统教材支持多套教材固定切换、树状章节浏览和课程视频播放。
- 学习视频支持目录扫描、真实视频封面卡片、弹窗播放和竖屏视频自适应。
- 歌曲练习支持 PDF/GP 打开、MP3 伴奏播放、进度条拖拽、A/B 打点循环和 0.60-1.00 变速。
- 小霞问答接入 MiniMax 国内 Token Plan Anthropic Messages 兼容接口。

### 技术
- 后端媒体接口支持 HTTP Range，解决视频、MP3、PDF、GP 预览/拖拽问题。
- 学习视频扫描自动生成 `.thumbnails` 封面并写入索引。
- `backend/.env` 本地读取 MiniMax 配置，并通过 `.gitignore` 防止密钥上传。
- 新增 `docs/DEVELOPMENT.md` 记录本地启动、配置、素材目录、扫描接口和验证命令。
