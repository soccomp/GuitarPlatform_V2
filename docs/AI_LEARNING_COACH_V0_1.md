# AI 学习教练 / 内容推荐系统 v0.1

编写日期：2026-05-04  
编写人：Codex

## 1. 目标

`v0.1` 的目标不是做“像真人老师一样实时纠错”，而是先做一个真正能帮助日常学习与练琴的：

- 学习内容分析器
- 下一步练习建议器
- 课程 / 视频 / 歌曲练习推荐器

一句话定义：

**AI 学习教练 v0.1 = 帮用户判断“我现在该练什么”，并把平台里相关的课程、学习视频和歌曲练习内容推到眼前。**

## 2. v0.1 先做哪些数据分析

### 2.1 内容侧分析

先分析平台里已经存在的学习资源，不碰复杂实时识别。

#### 系统教材

输入：

- 课程标题
- 课程层级
- transcript（未来生成）
- 已有标签

输出：

- 课程主题
- 重点知识点
- 推荐练习能力标签

示例标签：

- 节奏
- 主拍
- 切分
- 扫弦
- 拨弦
- solo
- 音阶
- 乐理
- 和弦
- 指板

#### 学习视频

输入：

- 视频标题
- 用户手工填写的介绍 / 备注
- transcript（未来生成）
- 分类 / 作者 / 标签

输出：

- 视频主题标签
- 适合解决的问题
- 与歌曲/课程的关联关键词

#### 歌曲练习

输入：

- 歌曲名
- 歌手
- 当前版本
- 已练习次数
- 练习速度分布
- AI 陪练历史摘要（如果可用）

输出：

- 当前歌曲练习热度
- 当前歌曲常见问题主题
- 当前歌曲关联能力标签

### 2.2 用户侧分析

`v0.1` 不做复杂用户画像，只做三个简单判断：

#### 1. 最近在练什么

根据：

- 最近练过哪些歌曲
- 最近看过哪些学习视频
- 最近打开过哪些系统课程

得到：

- 当前学习焦点

#### 2. 当前更缺什么

根据：

- 歌曲练习历史
- AI 陪练短反馈里的高频关键词
- 最近查看的课程/视频主题

粗判断当前更缺哪类能力：

- 节奏稳定
- 主拍控制
- 切分处理
- 基础拨弦清晰度
- solo 句子推进
- 乐理 / 指板理解

#### 3. 下一步最该练什么

根据：

- 当前焦点歌曲
- 当前薄弱能力
- 平台里是否已有相关课程/视频

得出：

- 1 个当前主练主题
- 2 到 3 个推荐学习内容
- 1 条短练习建议

## 3. 页面上怎么展示“下一步该练什么”

### 3.1 首页级入口

建议在平台首页或顶部加入一个新卡片：

- `AI 学习教练`

卡片内容非常克制，只显示：

- 你当前最该练的主题
- 推荐的 1 条主任务
- 2 到 3 个可直接点开的内容入口

示例：

```text
当前重点：主拍与进入点稳定
建议：今天先练《早班火车》2-4 小节，0.80x，10 分钟
相关内容：
- 系统教材：节奏与主拍基础
- 学习视频：早班火车 Solo 教学
- 歌曲练习：继续《早班火车》默认版
```

### 3.2 歌曲练习页展示

在歌曲练习页右侧或 AI 陪练上方增加一个新块：

- `下一步该练什么`

这个块只和当前歌曲相关，重点展示：

- 当前歌曲建议重点
- 对应系统课程
- 对应学习视频
- 一条短练习动作

示例：

```text
当前这首歌建议重点：主拍稳定 + 进入点
推荐课程：
- 左右手锻炼 / 节奏基础
推荐视频：
- Beyond_早班火车_solo
练习动作：
- 先循环 2-4 小节，0.80x，先不管装饰音
```

### 3.3 系统教材页展示

在系统教材页增加：

- `为什么推荐这节课`
- `适合当前解决什么问题`

例如：

- 你最近在《早班火车》中多次出现进入点不稳
- 这节课可用于补“主拍”和“切分进入”

### 3.4 学习视频页展示

在学习视频页增加：

- `推荐给你的原因`

例如：

- 你最近在练 Beyond 系歌曲
- 这条视频与《早班火车》solo 相关
- 当前适合补“句子推进感”

## 4. 怎么把相关课程和视频推送给你

### 4.1 推荐输入源

`v0.1` 推荐只使用平台内已有数据：

- 歌曲标题 / 歌手
- 学习视频标题 / 备注 / 标签
- 系统课程标题 / transcript / 标签
- 最近练习 / 最近播放 / 最近打开

### 4.2 推荐规则

先不用复杂模型检索，先做规则 + 轻量 AI 归纳。

#### 规则一：歌名关联

如果学习视频标题或备注里命中当前歌曲名：

- 直接视为高相关

#### 规则二：主题关联

如果课程 / 视频标签命中当前薄弱点：

- 视为主题相关

例如当前薄弱点是：

- 主拍
- 节奏
- 切分

则优先推带这些标签的课程和视频。

#### 规则三：近期焦点优先

如果用户最近反复练某首歌：

- 推荐内容优先围绕这首歌

#### 规则四：去重与裁剪

每次推荐最多只展示：

- 1 条主任务
- 2 节课程
- 2 条学习视频
- 1 首继续练的歌曲

避免推太多。

### 4.3 结果输出结构

建议后端输出一个统一结构，例如：

```json
{
  "focus_topic": "主拍与进入点稳定",
  "reason": "最近多次练习《早班火车》，且 AI 陪练反馈多次提到进入点和主拍边界问题。",
  "next_task": {
    "title": "继续练《早班火车》2-4 小节",
    "action": "保持 0.80x，先只练主拍和进入点，10 分钟"
  },
  "recommended_courses": [
    {
      "id": "course_xxx",
      "title": "节奏基础 / 主拍控制",
      "reason": "对应当前问题：主拍稳定性"
    }
  ],
  "recommended_videos": [
    {
      "id": "video_xxx",
      "title": "Beyond_早班火车_solo",
      "reason": "与当前练习歌曲直接相关"
    }
  ],
  "recommended_song": {
    "id": "song_xxx",
    "title": "早班火车",
    "version": "默认版"
  }
}
```

## 5. v0.1 最小可开发功能清单

### 5.1 后端

需要新增：

- `内容标签归一化`
  - 为课程、视频、歌曲建立统一主题标签
- `推荐服务`
  - 输入当前用户状态
  - 输出下一步建议和推荐内容
- `推荐接口`
  - 例如：`GET /api/coach/recommendations`

推荐服务第一版只依赖：

- 本地 index
- 练习历史
- 最近打开记录
- 简单规则匹配

### 5.2 前端

建议新增：

- 首页 `AI 学习教练` 卡片
- 歌曲练习页 `下一步该练什么`
- 推荐课程 / 视频 / 歌曲卡片
- 直接跳转按钮

### 5.3 数据准备

`v0.1` 需要先具备：

- 学习视频可编辑标题 / 介绍 / 分类
- 课程 transcript 逐步补齐
- 歌曲练习历史稳定保存

这些现在都已经开始具备基础。

## 6. 开发顺序建议

### 第一步

先做推荐数据结构，不做复杂 AI：

- 当前焦点歌曲
- 当前薄弱主题
- 课程 / 视频规则匹配

### 第二步

先在歌曲练习页落一个：

- `下一步该练什么`

因为这是你最核心的使用场景。

### 第三步

再把推荐扩展到：

- 系统教材页
- 学习视频页

### 第四步

最后再考虑：

- AI 参与生成更自然的推荐理由
- 更个性化的本周练习建议

## 7. v0.1 的成败标准

不是“AI 说得多像老师”，而是：

- 用户是否能更快知道现在该练什么
- 用户是否少花时间找资料
- 用户是否更容易从一首歌跳到对应课程和视频
- 用户是否愿意每天打开平台按推荐继续练

## 8. 最终判断

`AI 学习教练 v0.1` 最值得优先做的不是复杂智能，而是：

- 找重点
- 组织内容
- 建立关联
- 给出可执行的下一步

只要这四件事做顺了，它对练琴的帮助就会比“实验性的 AI 长篇点评”大得多。
